# Socle commun Taxi / Transporteurs sanitaires

Ce dossier contient uniquement les éléments partagés par les deux branches ou les deux modes B2/SEFi :

- `B2/` : normes communes, transport des flux, PEC+ et évolutions transverses ;
- `Services AMO/` : TLSi, information bénéficiaire, API Lecture Vitale et ApCV ;
- `SCOR/` : baseline commune 2.12 et exemples non chiffrés ;
- `Référentiels nationaux/` : COG, TOD, centres payeurs, FINESS+, RPPS et NOS ;
- `Droit et règles/` : prescription, prise en charge et règles nationales du transport partagé ;
- `Formulaires de facturation/` : fiches de diffusion communes ;
- `Technique/` : outils de validation locale, sans valeur normative.

Les conventions, tarifs, TUPH et annexes propres aux transporteurs sanitaires restent dans `30_TRANSPORTEURS_SANITAIRES/Métier TS/`. Les conditions ou annexes SCOR propres à une profession restent dans sa branche métier ; seule la baseline byte-identique est commune.

Les packages officiels présents ici ont été déplacés en bloc. Leur contenu n'a pas été corrigé ni recomposé.
