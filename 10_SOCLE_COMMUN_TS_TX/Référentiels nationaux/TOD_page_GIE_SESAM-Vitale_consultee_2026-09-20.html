TOD - Table des Organismes Destinataires

La Table des Organismes Destinataires (TOD)

Définition

Pour la génération des factures, le logiciel des professionnels de santé s’appuie dans certains cas sur un fichier, la Table des Organismes Destinataires (TOD). Celle-ci contient l'ensemble des codifications des différents organismes d'assurance maladie obligatoire : code régime, caisse gestionnaire, centre gestionnaire, libellé, organisme destinataire et code du centre informatique.

À partir des trois codes Régime/Caisse/Centre lus en carte Vitale, le logiciel de facturation calcule les adresses électroniques des centres payeurs auxquels doivent être envoyés les flux de feuilles de soins électroniques.

Cette TOD doit donc être téléchargée puis déployée par les éditeurs de logiciels dans le système d’information des professionnels de santé après chaque mise à jour publiée par le GIE SESAM-Vitale.

Téléchargement

⤓ Table de Codification des Organismes Destinataires - 17/02/2026
(version 3.76, format CSV compressé) + l'Historique des versions de la table des organismes destinataires.

La présente table constitue le document de spécification de référence pour ce type d'information, elle est utilisable en partie pour les SLM (code régime 99) par les logiciels agréés sur la base du Cahiers des Charges SESAM-Vitale. En effet, celui-ci inclut des règles de détermination automatique des organismes destinataires pour tous les autres régimes. Les informations proposées pour chaque organisme sont : le code régime, la caisse gestionnaire, le centre gestionnaire, le libellé, l'organisme destinataire, le code centre informatique.

Il est à noter que dans cette table, un code centre gestionnaire à 0000 correspond à "tous centres".

IMPERATIF :

Pour le régime général, utiliser l’adresse ci-dessous pour l'envoi des PJ de télétransmission et uniquement pour ces pièces.

Les Adresses des centres payeurs des organismes d'assurance maladie obligatoire

Cette table contient toutes les codifications des organismes d'assurance maladie (conformément aux spécifications IRIS / B2), ainsi que l'adresse postale des centres payeurs de ces mêmes organismes.

Cette table est mise à jour directement par les organismes d’assurance maladie obligatoire.

Si certaines informations étaient absentes, erronées ou obsolètes, n’hésitez pas à contacter votre Délégué(e) Numérique en Santé.

Explications des fichiers TOD

Rappel et informations

Attention : avant toute migration vers une nouvelle version de table des organismes destinataires, veillez à ce que le professionnel de santé ait télétransmis toutes ses FSE.

Rappel : La Table des organismes destinataires est mise à votre disposition sur notre site internet. Ce site est un site de communication et non un site de production. Par conséquent, l'adresse URL de ce fichier est susceptible d'être modifiée sans avertissement préalable. De plus, avant l'envoi de cette table dans les systèmes de production de vos clients, nous vous conseillons de la tester.
