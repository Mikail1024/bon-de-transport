# Branche Transporteurs sanitaires

- `B2/` : annexe métier TS et annexe de géolocalisation B2.
- `SEFi/` : package officiel 3.50, qualification CNDA 03.50.00, présérie, géolocalisation, annexes/sécurité SCOR propres aux TS, cartes et modèles papier TS.
- `Métier TS/` : convention, tarifs, TUPH, annexes TS du transport partagé et réunions historiques de géolocalisation.

Les normes communes, TLSi, baseline SCOR 2.12, référentiels nationaux et règles transverses sont dans [`../10_SOCLE_COMMUN_TS_TX/`](<../10_SOCLE_COMMUN_TS_TX/>).

Les erreurs des exemples officiels, notamment ServicePEC, sont décrites sans altération des sources dans [`../AUDIT_RECENT_TS_TX_2026-09-26.md`](<../AUDIT_RECENT_TS_TX_2026-09-26.md>).
