**Code d'accès personnel à Espace pro**

Vous vous connectez au service pour la première fois avec le code qui vous a été adressé par votre Caisse d'Assurance Maladie.
Avant d'accéder à l'ensemble des services en ligne que vous propose l'Assurance Maladie, vous devez choisir votre code d'accès personnel à Espace pro ainsi que votre question clé.
Ces éléments nous permettent de garantir la confidentialité de votre compte.

Vous devez remplacer votre code d'accès provisoire par un code d'accès personnel.

Votre code personnel Espace pro doit être composé de 6 à 13 chiffres et lettres, avec au moins un chiffre, et en respectant les minuscules et majuscules.

## Que faire en cas de code d’accès oublié ou de compte bloqué?

Accéder au portail : [https://espacepro.ameli.fr](https://espacepro.ameli.fr/)

Cliquez sur le lien :
**Code d’accès oublié ou compte bloqué**

Puis deux possibilités :

screenshot: Accéder à Espace pro

screenshot: Espace pro - Le nouvel espace des professionnels de santé

**1**
**Code d’accès oublié ou compte bloqué** dans le bloc "Accès sans carte CPS".

**2**
**Code d’accès perdu ou oublié - Demande d’envoi d’un code d’accès**
Si vous avez oublié ou perdu votre code d’accès ou que votre compte est bloqué, veuillez saisir ci-dessous le numéro d’Assurance Maladie de votre lieu d’exercice (9 caractères).
Un nouveau code d’accès vous sera adressé par courrier.

Saisissez votre numéro d’Assurance Maladie [ ]
*Exemple : 012345678*

> **<u>L’Assurance Maladie n’a pas connaissance de votre adresse électronique :</u>**
> **vous recevrez votre code d’accès par la poste, il conviendra de le personnaliser à nouveau.**

**3**
**Code d’accès perdu ou oublié - Question clé**
Votre question clé [Nom de votre chien]
Saisissez votre réponse [•••••]

Nous disposons de l’adresse électronique suivante : fr[..........]
Vous pouvez ainsi recevoir directement votre code d’accès provisoire par courriel.
Toutefois, si votre adresse électronique est erronée, choisissez l’envoi du code par courrier.

(•) Je souhaite recevoir mon code provisoire par courrier électronique
( ) Je souhaite recevoir mon code provisoire par courrier postal sous un délai de huit à dix jours.

> **<u>L’Assurance Maladie a connaissance de votre adresse électronique :</u>**
> **On vous présente votre question clé , il suffit de saisir la réponse appropriée, de cocher l’option courriel, puis « valider » pour recevoir un <u>nouveau code instantanément</u> dans votre messagerie, il conviendra de le personnaliser à nouveau.**

**Vous n’arrivez pas à vous débloquer?**

une hotline au ~~0811 709 710~~
